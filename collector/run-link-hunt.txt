# ⭐ 이 로봇의 목적: 다른 수집 로봇이 못 잡은 원문 공고를 **어떻게든** 찾아서 올려둔다.
#    특정 학교에 묶지 말 것 — 기본이 전체 학교다.
#
# onlyBoard: (선택) 게시판 하나만. 줄이 없으면 전체 학교 ← 기본값
# maxPages:  목록을 몇 페이지까지 넘겨볼지 (기본 10)
# patrol:    한 번에 다시 열어 볼 기존 링크 수 (기본 40, 0이면 순찰 끔)
maxPages: 14
patrol: 60

run: 2026-08-01 — 끈질기게 3단계 구조로 전면 개편
  ① 학교 제한 없음 (전체)
  ② 순찰: 기존 링크도 돌아가며 다시 열어 봐서 '학생이 못 보는 링크'를 찾아낸다
  ③ 포기 없음: 못 찾으면 간격을 늘려 가며(1→3→7→14→30일) 계속 다시 찾는다
  ④ 다른 경로: 기록된 게시판에 없으면 같은 학교의 다른 게시판 + 학교 사이트 검색까지
