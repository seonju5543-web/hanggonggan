## 한 줄 요약

학교 게시판에서 로봇이 **이미 주워 오던 행** 가운데 장학 피드가 버리던 공모전·서포터즈 글을 갈라 담아
(`data/activities.json`) 아래 탭 다섯 번째 「대외활동」에 **제목+링크 목록**으로 보인다.
자격 판정·적합도·양식은 붙이지 않는다 — 원문을 읽지 않은 것을 판정하지 않는다(운영 원칙 8-1).

## 크롤링 출처 — 왜 새 사이트를 붙이지 않았나

| **두 학교의 대외활동·공모전 전용 게시판** (취업·비교과·학생활동 게시판) | ✅ 자리만 | `collector/activity-sources.json` 에 두 학교 항목을 `boardUrl: null` 로 두었다. 로봇은 매 실행 리포트에 「⚙️ 게시판 주소 미설정」으로 적는다. 🔴 **주소는 개발자가 확인해 적는다** — 로봇은 검색을 못 하고 Claude 세션은 주소를 추천하지 않는다(CLAUDE.md 매 세션 6). 샌드박스에서는 학교 사이트가 열리지 않아 이번 세션이 확인할 수도 없었다. |

## 기능 추가 방식 — 결정 다섯

1. **파일을 섞지 않는다** — `data/notices.json` 이 아니라 `data/activities.json`.
   섞으면 ① `notify-rules`·`server/push` 가 「우리 학교 새 공고 N건」으로 세어 **장학 알림이 활동 글로 울린다**
   ② `dropUnserved` 가 학교 없는 전국 글을 버린다 ③ 「서비스하지 않는 학교의 공고는 피드에 안 담는다」 관문이 깨진다.
   장부도 따로다(`collector/seen-activities.json`) — 장학 장부에 '봤다'로 적힌 글도 활동으로는 처음이다.
2. **판정은 한 곳** — `collector/activity-kind.mjs` `activityKind(title, { scholarship: KEYWORDS })`.
   순서가 규칙이다: 행정 안내(출근부·결과 발표·채용·대출) → 아님 · 공모전 낱말 → 공모전(장학수기 공모전은 장학 낱말이 있어도 공모전) ·
   장학 낱말 → 아님(봉사장학·인턴장학·서포터즈 장학생은 **장학 제도**라 장학 카드가 정답) · 활동 낱말 → 대외활동.
   장학 낱말 규칙은 `collect.mjs` 의 `KEYWORDS` 를 **넘겨받는다**(베끼면 두 벌).
3. **로봇은 새로 만들지 않았다** — `collect.mjs` 가 같은 실행에서 같이 쓴다. 새 워크플로를 만들면 deploy-sync 목록·예약 겹침·
   MUST_RUN 등록을 다 해야 하고, 같은 게시판을 하루 두 번 두드린다. 60일 삭제·중복 제거·서비스 학교·상한 200 규칙은 장학 피드와 같다.
   전용 게시판(`role:'activity'`)은 장학 피드에 담지 않는다. 전용 게시판 상태는 health.json 에 넣지 않는다(prune-health 가 schools.json 이름으로 고아를 지운다) — 리포트에만 적는다.
4. **화면은 탭 하나 + 칩 셋** — 「대외활동」탭 안에서 전체/대외활동/공모전. 탭을 둘로 나누면 아래 바가 여섯 칸이 된다.
   카드는 `noticeCardHtml(n, { org })` **한 벌**(윗줄만 '공모전 · 경희대학교 게시판'으로) — 카드 두 벌 사고(2026-09-11) 재발 방지.
   학교 범위는 `match-engine.js` `activityForProfile` (학교 글은 `noticeForProfile` 과 같은 잣대 · 학교가 빈 글은 전국).
   정렬은 최근 수집 순 하나 — 마감일을 모르는 목록이라 마감순은 거짓이 된다(원문 한 줄 `deadlineHint` 만 보인다).
   화면 위치는 `#screen-explore` **뒤** — 관문 「교내·교외 분류와 주관 기관」이 홈~탐색 사이를 잘라 재기 때문.
5. **손으로 적은 목록 여섯 곳에 다 넣었다** — `showScreen` 화면 목록·그리기 분기·`rerenderVisible`·`refreshAllData`·첫 실행 로더·
   `resume.js RESUME_TABS`·`notify.js` 딥링크. 관문이 여섯 곳을 전부 잰다(하나 빠지면 그 길에서만 탭이 죽는다).

## 개발자가 정할 것 (이 세션이 손대지 않은 것)

1. **전용 게시판 주소** — `collector/activity-sources.json` 두 항목의 `boardUrl`. 적어서 기본 브랜치에 push 하면 다음 07:41 수집부터 읽는다.
2. **모음 사이트·공공 API를 붙일지** — 붙이면 같은 파일에 `{ "school": "", "host": "…", "boardUrl": "…" }`.
3. **알림** — 활동 글은 지금 알림·푸시 대상이 아니다(일부러). 원하면 `notify-rules.js` TYPES 에 종류를 더하고 설정 스위치를 단다.
4. **탭 이름·아이콘** — 「대외활동」(트로피). 화면 캡처는 세션 보고에 첨부했다.
