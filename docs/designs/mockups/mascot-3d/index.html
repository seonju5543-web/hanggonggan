이 시안에서 정한 것 · 아직 안 정한 것

  • 금액은 누르지 않아도 처음부터 말풍선 안에 보입니다. 누르는 것은 재미일 뿐, 정보를 숨기지 않아요.
  • 카드와 「n건 신청 준비」 버튼을 없앴어요(11-19 결정). 신청 내역도 남색 카드 대신 대장님이 알려 줍니다.
  • 모든 마스코트가 과잠을 입습니다. 원래 다른 옷이 정체성인 캐릭터(유생 옷·비행복 등)는 원작 변형이에요.
  • 학교 공식 캐릭터를 앱에 싣는 것은 학교 허락이 필요해요 — 이 시안은 내부 검토용입니다.
  • 지금 모양은 코드로 빚은 조형입니다. 최종 품질은 3D 모델 파일로 바꿔 끼우면 돼요.
