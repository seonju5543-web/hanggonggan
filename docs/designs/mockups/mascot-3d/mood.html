반응이 움직이는 방식

  • 화남(1초에 4번 넘게 연타 · 약 6초) — 볼이 빨개지고 머리에서 김이 나요(눈썹은 없어요). 실제로 사람이 겉옷을 벗는 차례와 투수가 공을 세게 던지는 동작을 찾아보고 그대로 짰어요.
    1. 과잠 벗기(1.8초) — 어깨를 펴고 턱을 당겨 노려봐요 → 두 손으로 앞판을 움켜쥐고 확 젖혀 열어요(똑딱단추가 위에서 아래로 튀어요) → 어깨 뒤로 흘려 내리고 → 몸을 틀어 팔을 한쪽씩 소매에서 홱 빼요 → 빠진 과잠을 쥐고 머리 옆으로 치켜들었다가 바닥에 패대기치고 발을 쾅. 과잠은 보지 않고 화면을 노려본 채 손으로만 벗어요. 입은 과잠을 몸통째 움직이지 않고 좌우 두 쪽으로 갈라 몸의 세로축으로만 돌려 여니 몸을 뚫거나 일그러지지 않아요.
    2. 몽둥이 줍기(0.7초) — 옆으로 기울여 바닥의 몽둥이를 쥐고 던질 준비 자세로.
    3. 던지기(1.2초) — 투수의 6단계 그대로: 반대로 살짝 → 앞발을 들어 몸을 닫고(와인드업) → 화면 쪽으로 내디뎌 → 몽둥이를 머리 바깥으로 가장 뒤까지 젖혔다가 → 팔꿈치가 앞서고 몽둥이가 뒤따라 채찍처럼 → 놓는 순간 휴대폰 화면 전체(장학금 공고·실시간 공고까지)로 몽둥이가 날아와 유리가 깨져요 → 팔이 몸을 가로질러 내려가요. 디딘 발은 바닥에 붙어 있어요.
    4. 허리에 손, 고개 홱, 발 동동 → 바닥의 과잠을 주워 어깨 뒤로 휙 걸치고 팔을 한쪽씩 넣어 앞판을 여며요.
    대장님은 과잠 대신 씩씩대다 학사모가 튕겨 바닥에 떨어지고, 끝날 때 다시 머리로 날아와요.
  • 어지러움(세게 빙글빙글 돌리기) — 눈이 소용돌이, 머리 위로 별이 돌고 비틀거려요(2초).
  • 좋아함(0.7초 넘게 길게 누르기) — 눈을 감고 볼이 분홍, 하트가 떠올라요(손을 뗄 때까지).
  • 찌그러짐(아래로 끌어당기기) — 끄는 만큼 납작해졌다가 놓으면 튕겨 올라요.
  • 졸기(20초 동안 안 건드림) — 꾸벅꾸벅 Zzz. 누르면 「!」 하고 깜짝 놀라 깨요(이때는 동전이 안 나와요).
  • 수령 가능액을 가리킬 때 — 네모난 검은 뿔테의 비즈니스 선글라스를 끼면 회장님 의자가 옆에서 묵직하게 굴러 들어와요. 머리 위까지 오는 높은 등받이, 다이아몬드 단추 누빔 가죽, 머리 옆 날개, 둥글게 말린 팔걸이와 놋쇠 못, 크롬 다섯 갈래 바퀴 다리(실제 고급 중역 의자를 찾아보고 앞에서 잘 보이는 곳에 공을 들였어요 · 과잠이 빨간 학교는 검은 가죽). 폴짝 뛰어 앉아 등을 깊이 기대고, 두 발은 좌판 앞에서 발목을 꼬아요(무릎이 없는 몸이라 다리를 배 위로 올리면 혹처럼 보였어요 · 윗발은 2초에 한 번 느긋하게 흔들어요). 팔걸이에 얹은 손이 1초 가만히 있다가 옆으로 무심하게 툭 — 지폐가 위로 흩날려요. 의자째 가끔 살짝 좌우로 돌아요.
  • 마감 D-Day를 가리킬 때 — 「이럴 수는 없어」. 깜짝 놀라 두 손을 번쩍 들었다가 몸수색 받는 사람처럼 손을 뒤통수 뒤로 접어 숨겨요(앞에서 손이 안 보여요 · 어깨를 으쓱하고 팔꿈치를 벌려요) → 발을 벌리고 번갈아 동동(천천히 들고 빨리 쾅). 머리 옆 식은땀이 흘러내려요(가장 빠른 마감이 오늘일 때만 — 위 「가장 빠른 마감」 칩).
  • 말풍선은 없어요 — 몸짓과 표정만으로 말해요.
  • 화내거나 조는 동안은 줄이 저절로 넘어가지 않아요. 보통 한 번 누르기는 지금처럼 뛰며 동전이 나와요.
  • 휴대폰에서 '동작 줄이기'를 켠 학생에게는 표정과 끝 자세만 보이고 과잠 벗기·던지기·흔들림·지폐·발 구르기는 빠져요.
  • 🔴 화남은 손짓에만 반응해요 — 마감을 놓쳤다거나 신청을 안 했다는 이유로 화내지 않아요.
