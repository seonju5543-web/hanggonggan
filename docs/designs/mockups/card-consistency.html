카드 일관성 시안

출처 여섯 곳의 실제 데이터 카드입니다. 왼쪽이 지금 화면, 가운데·오른쪽이 제안 둘. 글자는 지우거나 자리를 옮기기만 했고 한 글자도 더하지 않았습니다(원칙 8-1). 제안 둘은 뼈대가 같고 「기간을 줄로 적느냐, D-day 로만 말하느냐」가 다릅니다.

지금출처마다 다름

  1. 장학 카드: 구분·주최 / 제목 / 금액 · D-day
  2. 활동 카드: 주최 · D-day / 제목 / 이름표 줄 1~3개(출처마다 다른 이름표) / 첨부·수집일·원문 줄
  3. 제목은 게시판 글 그대로(「(대학생,대학원생만)…(※토 4회…)」·「공통 …」)
  4. 모르는 칸은 「금액 원문 확인」 같은 글자가 카드에 남음

시안 A — 같은 뼈대 네 줄제안

  1. 윗줄: 갈래 칩(장학 교내·장학 교외·봉사·대외활동·청년정책) + 주최(알 때만)
  2. 제목: 앞머리 괄호·「※…」 꼬리는 대상 줄로 옮김 · 게시판 머리말(공통)·끝 마침표 뗌
  3. 핵심 한 줄: 장학 = 금액 · 활동 = 대상 · 모르면 줄 자체가 없음
  4. 기간 한 줄: 「접수 10.13 ~ 11.02 · D-DAY」 한 꼴 · 활동기간·지역·혜택·첨부·수집일은 상세로

시안 B — 최소형제안

  1. 윗줄·제목·핵심 한 줄은 A 와 같음
  2. 기간 줄 없음 — D-day 배지 하나가 마감을 말함(기간 전문은 상세로)
  3. 그래서 카드는 늘 세 줄, 장학·활동이 완전히 같은 높이
  4. 접수 시작일이 중요한 글(아직 안 열린 접수)은 상세에서만 보임 — 이게 B 의 대가

두 시안이 공통으로 바꾸는 것 · 코드로 가면 어디가 바뀌나

  • 이름표 어휘 하나 — 모집기간·신청기간·접수기간 → 「접수」 · 지원대상·모집대상·참가자격 → 「대상」 · 지원금액·장학금액 → 「금액」. 값은 원문 그대로. (화면 한 곳 · 출처 다섯이 같은 함수를 지난다)
  • 제목 나누기 — 앞머리 괄호 「(대학생,대학원생만)」·「※…」 꼬리를 떼어 대상 줄로. 날짜를 떼는 지금 규칙(`splitTitleDates`)과 같은 자리에 같은 방식으로. 「…를 모집합니다.」 같은 문장형 제목은 끝 마침표만 뗀다 — 문장을 고치면 남의 제목이 된다.
  • 빈칸 글자 없음 — 못 읽은 금액·대상·주관은 줄이 없다. 상세 시트에는 지금처럼 「원문 확인」이 남는다(감추는 게 아니라 자리를 옮긴다).
  • 층2 긴 금액은 ○ 글머리만 떼고 옅게 — 숫자 하나로 요약하지 않는다(「최대 150만원」만 남기면 조건을 지우는 것).
  • 이 시안이 못 고치는 것 — 자격 줄 자체가 깨진 글(반영장학의 「ㅣ - 신청자격: !」)은 카드 뼈대가 아니라 첨부 글자 읽기(OCR)의 문제라 따로 잡아야 한다.
