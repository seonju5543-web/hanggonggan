# 지도 로드맵 — 학교 은어 · 주변 장소 리뷰 · 커뮤니티 (설계)

> 2026-10-10 · 유은서(CTO) · 팀 업무 분장 프론트 16번
> 지시: "지도 로드맵 API 삽입: 학교 은어, 주변 술집/과팅 장소/카페 리뷰 및 커뮤니티 개설"
> 상태: **설계까지.** 지도 API 열쇠 발급(개발자 몫)과 아래 🔴 결정 3개가 있어야 만든다.

## 1. 무엇을 만드나

학교를 고르면 그 학교 주변 지도가 뜨고, 그 위에 세 겹이 올라간다.

| 겹 | 내용 | 데이터 출처 |
|---|---|---|
| 장소 | 카페 · 술집 · 과팅 장소 · 공부 장소 | 지도 API의 장소 검색(가게 이름·위치·영업시간) |
| 리뷰 | 우리 학생이 쓴 한 줄 평 + 별점 | **우리 장부**(Supabase `place_reviews`) |
| 학교 은어 | "중도 = 중앙도서관" 같은 학교 말 사전 + 건물 위치 핀 | 학생이 등록 → 추천 수로 정렬 |

커뮤니티는 리뷰·은어에 댓글이 붙는 형태로 시작한다(게시판을 따로 크게 만들지 않는다).
과팅 앱(백엔드 6·7번)이 같은 장소 데이터를 쓴다.

## 2. 지도 API 고르기

| | 카카오맵 | 네이버 지도 | 구글 지도 |
|---|---|---|---|
| 국내 가게 정보 | 좋음 | 좋음 | 부족 |
| 무료 한도 | 넉넉함(일 30만 회 수준) | 월 사용량 기준 무료 구간 | 월 $200 크레딧 |
| 장소 검색 API | 있음(키워드·카테고리) | 있음 | 있음 |

**권장: 카카오맵.** 대학생 사용성·무료 한도·장소 카테고리(카페 CE7, 음식점 FD6 등)가 맞는다.

## 3. 🔴 보안 설정과 부딪히는 점 — 결정 필요

앱은 **우리 파일 밖의 스크립트를 실행하지 않는다**(index.html CSP `script-src 'self'`).
수집한 공고에 나쁜 코드가 섞여도 실행되지 않게 하는 핵심 장치다(CLAUDE.md "SDK를 쓰지 않는다" 결정과 같은 이유).
카카오 지도는 카카오 서버의 스크립트를 불러와야 그려진다. 길은 셋이다.

| 안 | 방법 | 장점 | 단점 |
|---|---|---|---|
| A | 지도 화면만 **별도 페이지**(`map.html`)로 분리하고 그 페이지에만 카카오 허용 | 앱 본체 방어선 유지 | 화면 전환이 페이지 이동 |
| B | 앱 전체 CSP에 `dapi.kakao.com` 허용 | 구현 간단 | 방어선이 카카오 한 곳만큼 넓어짐 |
| C | 지도 그림 없이 **목록 + "지도에서 보기" 링크**(카카오맵 앱으로 이동) | 외부 스크립트 0, 오늘 바로 가능 | 지도가 앱 안에 안 보임 |

**권장: C로 먼저 시작 → 반응을 보고 A.** C는 장소 검색만 서버(Cloudflare Worker)에서 하고 결과를 목록으로 보여 준다.
열쇠도 서버에만 두므로 노출되지 않는다.

## 4. 데이터 · 운영 규칙

- 리뷰·은어는 **학생이 쓰는 글**이다 → 신고·숨김 기능, 욕설 걸러내기, 운영자 삭제 권한이 처음부터 있어야 한다.
- 가게에 대한 허위 비방은 법적 분쟁 소지가 있다 → 이용약관에 게시물 책임·삭제 조항 추가(`terms.html`).
- **지어낸 리뷰·별점을 초기 데이터로 넣지 않는다**(운영 원칙 6 가짜 공지 금지와 같은 정신). 처음엔 비어 있는 것이 정직하다.
- 술집 정보는 만 19세 미만에게 노출하지 않는다(고등학생용 과외 앱과 장부를 공유하므로 서버에서 나이 확인).
- 위치는 **학교 위치 기준**으로만 검색한다. 학생의 현재 위치를 받으면 위치정보법 동의·고지가 추가된다 → 처음엔 받지 않는다.

## 5. 만드는 순서
1. (개발자) 카카오 개발자 앱 등록 → REST 열쇠를 **Cloudflare 시크릿**에 저장 (채팅에 붙여 넣지 않는다)
2. `server/places/` Worker: 학교 좌표 + 카테고리 → 장소 목록 (1일 캐시)
3. 앱: 찾기(또는 새 탭)에 「학교 주변」 — 목록 + 카카오맵 링크 (안 C)
4. Supabase `place_reviews` · `campus_slang` 표 + 자기 글만 고치는 규칙(RLS) + 신고 표
5. 반응이 좋으면 지도 그림(안 A)

## 6. 정할 것
1. 안 C로 시작해도 되는지 (외부 스크립트를 앱에 들이지 않는다)
2. 이 기능이 한대장 안에 들어가는지, 과팅 앱 쪽에 들어가는지 (술집·과팅 장소는 과팅 앱이 더 맞다)
3. 카카오 개발자 앱 등록 담당
