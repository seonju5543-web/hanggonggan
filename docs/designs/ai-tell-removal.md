## 1. 뿌리 원인 넷 — 증상 스무 개가 여기서 나온다

### ① 템플릿이 자기 빈칸을 읽어 준다 (가장 깊다)

앱이 실제로 아는 것:

| 아는 것 | 48건 중 | 비율 |
|---|---|---|
| 금액 | 14건 | **29%** |
| 마감일 | 34건 | 71% |

그런데 카드에는 금액 자리가 **고정으로** 있다. 그래서 10건 중 7건에서 카드의 가장 굵은 줄이
`금액 원문 확인` — 금액이 아니라 **지시문**이 된다. 자격도 같다(`자격 미확인`),
마감도 같다(`기한 원문 확인`).

이 앱은 원칙 8-1(추론 금지) 때문에 **일부러** 모르는 것을 모른다고 말한다. 그 원칙은 옳다.
문제는 **모른다는 사실을 아는 것과 같은 자리·같은 크기·같은 무게로 말한다**는 것이다.
사람이 만든 화면은 모르는 칸을 **접는다.** 접을 수 없으면 작게, 아래로, 회색으로 내린다.

> 🔴 처방이 "모르는 것을 감춰라"가 되면 안 된다. 원칙 위반이다.
> 처방은 **"모르는 칸은 같은 무게로 말하지 않는다"** 이다.

### ② 엔진이 재는 축을 전부 배지로 낸다

한 카드에 배지가 **최대 5개** 붙는다: `적합도 33%` `교외` `D-1` `검수 전` `신청 완료`.
배지는 넣기는 쉽고 빼자는 말은 아무도 안 한다. 그래서 계속 늘었다.

- `검수 전` 은 **우리 내부 검수 공정 상태**인데 48건 중 20건(42%)에 붙어 학생 화면에 나간다.
- `적합도 NN%` 는 목록에서 대부분 33~50%에 몰려 있어 **순서를 정하는 것 말고는 아무 말도
  못 하면서**, 학생에게는 "내가 33점짜리"로 읽힌다.

사람이 만든 목록은 한 줄에 판정을 **하나만** 놓는다. 다섯을 다 놓는 것은
「아는 것을 전부 표시한다」는 **기계의 습관**이다.

### ③ 규칙은 세웠는데 관문이 없어서 되돌아갔다

2026-09-01 개발자 지적 *"간격이 맞지 않은 부분이 많다"* → 세로 간격을 네 단계로 못 박고
`style.css` 머리말에 *"숫자를 직접 쓰지 말 것"* 이라고 적었다. 오늘 세어 보니:

| | |
|---|---|
| 토큰(`--sp-1~4`)을 실제로 쓴 곳 | **24곳** |
| 생 px 여백 | **521곳 · 서로 다른 값 40종** |
| **토큰을 만든 뒤에 새로 쓴** 생 px 여백 | **104곳** |

같은 파일에서 모서리·글자크기·그림자는 **관문이 있어서** 깨끗하다. 여백·색은 **주석만 있어서**
되돌아갔다. 이 저장소가 이미 아는 교훈 그대로다 —
**안내문에 적는 것은 리포트고, 강제하는 것은 관문이다.**

색도 같다. 팔레트(`:root`) 밖에서 직접 쓴 유채색이 **67종 · 95곳**이고,
`:root` 에 **아예 없는 토큰에 폴백을 단 곳이 4종**이다:

```
--chip-bg  --card-bg  --bg-sub  --muted
```

없는 토큰이므로 **폴백 색이 그대로 화면에 뜬다.** 실제로 `자격 미확인` 배지는
`var(--chip-bg, #eceff3)` 라서 팔레트에 없는 회색 `#eceff3 / #6b7280` 으로 떠 있다.
게다가 폴백 값이 진짜 토큰 값과 다른 것이 10종 있다(예: `--orange` 실제 `#8a5a12`,
폴백 `#e08a1e`) — **옛 팔레트를 보고 쓴 줄이 남아 있다는 뜻**이다.
지금 화면은 팔레트 세 세대가 겹친 결과다.

### ④ 목소리가 여러 명이다

같은 「없다」를 화면마다 다르게 말한다 — `app.js` 에서 실제로 센 것:

| 문구 | 위치 | 말투 |
|---|---|---|
| `담아 둔 장학금 없음` | app.js:896 | 개조식(명사 종결) |
| `저장한 공고가 없어요.` | app.js:2631 | 구어체 해요 |
| `아직 준비한 장학금이 없습니다.` | app.js:2680 | 격식체 습니다 |
| `지금 신청 가능한 장학금 없음 · 프로필 업데이트 권장` | app.js:890 | 개조식 + 중간점 + 명령 |

마감도 **다섯 가지 형식**이다: `M/D`(막대) · `M월 D일 HH:MM`(홈 하단) · `YYYY-MM-DD`(상세) ·
`YYYY.MM.DD`(신청 기록) · `D-n`(배지). **홈 한 화면에 세 가지가 동시에 뜬다.**

각 줄은 쓸 때마다 맞았다. 아무도 전체를 소유하지 않았을 뿐이다.
전문가가 말한 *"말투에서 앱을 AI로 제작했다는 사실을 알아차린다"* 의 실체가 이것이다.

## 3. 오늘 넣은 것 — 관문 하나 (화면은 한 픽셀도 안 바꿨다)

`verify/ui-tone.mjs` 에 **톱니(ratchet)** 를 걸었다. 지금 값을 천장으로 적어 두고 **늘어나면 실패**한다.

```
■ 토큰 이탈이 더 늘지 않는다 (톱니 · 2026-09-10)
  ✓ 여백을 토큰(--sp-1~4) 대신 생 px 로 쓴 곳: 521 (천장 521)
  ✓ 팔레트(:root) 밖에서 직접 쓴 유채색: 95 (천장 95)
■ 없는 토큰에 폴백을 달지 않는다
  ✓ 선언된 적 없는 토큰에 단 폴백: 4 (천장 4)
```

- **왜 0을 요구하지 않았나** — 521곳을 한 번에 고치는 것은 화면을 통째로 바꾸는 일이라
  개발자 승인 없이 할 수 없다(`.claude/skills/approved-design`). 대신 **오늘 안 고쳐도
  내일 더 나빠지지는 않게** 했다. 줄이면 "천장을 내리라"고 스스로 알린다.
- **red-green 확인함** — 셋 다 일부러 어겨서 빨간불이 뜨는 것을 보고, 되돌려 초록불을 확인했다.
- 이미 `.github/workflows/verify-ui.yml` 이 `ui-tone.mjs` 를 돌리므로 **자동으로 걸린다.**
- 세는 데서 뺀 것 셋: `.chat-*`(개발자 지시) · `.fd-*`/`.form-doc`(인쇄 문서라 흰 종이·검은 글씨가 맞다) · `@keyframes`.

## 4. 개발자 결정이 필요한 것 — Figma 에서 보고 정해 주세요

화면·문구를 바꾸는 것은 승인 대상이라 **코드에 넣지 않고 Figma 에만 그렸다.**

| # | 제안 | 효과 | 품 | 걸리는 것 |
|---|---|---|---|---|
| 1 | **카드에서 `검수 전` 배지를 빼고 상세에만 둔다** | 48건 중 20건(42%)의 카드에서 배지 하나가 사라진다 | 작음 | 운영 원칙 2가 "정직하게 표시"를 요구한다 → 상세에 남기면 지켜진다 |
| 2 | **제목에서 기관명 접두어를 지운다**(아래 줄에 이미 있다) | 카드 제목이 짧아지고 두 줄 → 한 줄이 된다 | 작음 | 없음 |
| 3 | **마감 표현을 한 가지로 통일**(`20일 남음` / `내일 마감` / `오늘 마감`) | 다섯 형식 → 하나 | 중간 | `dday()` 한 곳만 고치면 된다. 달력은 날짜가 필요하니 예외 |

| 5 | **목록에 네 구획**(오늘·내일 / 이번 주 / 이번 달 / 마감 미정) | 46,626px 평면이 끊긴다 | 중간 | 🔴 구획은 **마감일 하나로만** 가른다. 접수 시작일은 48건 중 17건뿐이라 「접수 기간의 %」를 지어내면 원칙 8-1 위반 |

## 5. 하지 말아야 할 처방 (검토 중에 걸러낸 것)

- ❌ **"모르는 것을 감춰라"** — 원칙 8-1 위반. 무게를 낮추는 것과 감추는 것은 다르다.
- ❌ **"사진·일러스트를 넣어 인스타처럼"** — 이 앱에는 넣을 사진이 없다. 공고에는 이미지가 없고,
  지어낸 이미지를 붙이는 것은 원칙 6(가짜 공지 금지)의 정신에 어긋난다.
  인스타의 '살아 있음'은 사진이 아니라 **시간의 흐름**에서 온다 — 그건 구획(제안 5)이 준다.
- ❌ **"그라데이션·글래스모피즘으로 요즘 느낌"** — 2026-08-31 팔레트 정리가 이미
  "그라데이션은 AI 지문"으로 판정하고 관문을 세웠다. 되돌리지 않는다.
- ❌ **대장님(`.chat-*`) 손대기** — 2026-08-29 개발자 지시로 제외 영역이다.
