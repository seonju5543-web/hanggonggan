## 2. 어떻게 만들어졌나 (코드 자리)

🔴 **영상 파일(mp4)이 아니다 — 사진 3장 + CSS 움직임이다.** 보이는 것은 승인받은 컷 A 와 같은데
서비스워커 3.5초 시한 · iOS 저전력 자동재생 차단 · 움직임 줄이기 설정 문제가 전부 없어진다.

| 자리 | 하는 일 |
|---|---|
| `index.html` 0단계 블록 | 무대(`#start-stage`) · 스크림 SVG · 워드마크 · 카피 · 버튼. **사진을 박아 두지 않는다** |
| `style.css` 맨 끝 '시작 화면' 절 | 토큰(`--start-base/-ink/-band/-dur`, `--t-start`) · 장면 움직임 · 자리 |
| `app.js` `startMontage()` | `assets/gates/gates.json` 에서 **무작위 3장**을 골라 무대에 넣고, 덮개가 열릴 때 돌린다 |
| `boot.js` | 덮개에 구멍이 뚫리는 순간 `boot:open` 을 보낸다 (그때 첫 사진이 스며든다) |
| `assets/gates/` | 앱이 받는 사진 14장(가로 1000px 사본 · 1.8MB) + `gates.json`(목록·초점·출처 줄) |
| `tools/gate-reel/` | 승인받은 컷 A 를 그린 `reel.html` + 녹화 `cut.mjs` + `build-app-gates.mjs` + README |
| `docs/designs/assets/gates/` | 원본 사진 14장 · `manifest.json` · **출처 표 `PICKS.md`** · 컷 A·B mp4(`cuts/`) |

움직임: 장면당 0.35초 페이드인 → 1.00→1.10 확대 → 0.35초 페이드아웃, 마지막 장면은 멈춘다.
**한 번 재생하고 끝이다**(앱 원칙). 움직임 줄이기 기기에서는 사진 한 장만 그대로 보인다.

## 3. 🔴 되돌리면 깨지는 것 넷 (전부 실측으로 드러났다)

1. **`.onboard-step[data-step="0"]` 의 `flex: none`** — 빼면 `.onboard-step` 의 `flex: 1`
   (= `flex-basis: 0%`)이 세로 flex 안에서 height 를 무시해 **0단계 높이가 0** 이 된다.
   첫 판이 그랬다: 버튼 top −159px · 스크림 0×0 — 카피와 버튼이 화면 위로 나가 있었다.
2. **`.start-stage.start-done`** — 1단계로 갔다 돌아오면 0단계가 `display:none` 에서 다시 보이는
   것이라 **CSS 애니메이션이 셋 다 처음부터 다시 돈다**(실측: 돌아온 0.3초 뒤 세 장면이 전부 0.81).
   `startMontage` 가 마지막 장면이 끝나는 시각에 이 클래스를 달아 멈춘 상태를 굳힌다.
3. **스크림은 `index.html` 의 인라인 SVG** — `style.css` 에 CSS 그라데이션으로 옮기면
   `ui-tone.mjs` 의 '그라데이션은 --grad-navy 한 곳' 관문이 잡는다.
4. **`:has()` 로 이 화면만 여백을 거둔다** — `.screen` 20px 과 `.app` 아래 148px.
   안 거두면 사진이 화면 끝에 안 닿고 **148px 헛스크롤**이 남는다.

## 4. 사진은 어디서 왔나 · 라이선스

전부 **위키미디어 공용의 열린 라이선스** 사진이다(CC0 · CC BY · CC BY-SA). 대학 공식 홈페이지
사진은 저작권이 학교에 있어 **쓰지 않았다.** 출처·작가·표기 문구는 `docs/designs/assets/gates/PICKS.md`.

로봇 `tools/fetch-gate-photos.mjs` 가 Commons API 로 받는다(push-to-run `tools/run-gate-photos.txt`).
샌드박스가 위키미디어를 막아 GitHub Actions 로 돌린다. 4차에 걸쳐 걸러 낸 것:
창덕궁 그림 · 서울대병원 정문 · 서강대역 · 분교 캠퍼스 · 학교 로고 — 그래서 **제목에 학교 이름이
있어야 받고**(must) 분교·역·병원·로고는 뺀다(not). 줄임말 제목(`SeoulNatlUniv`·`Chung-ang`)도 받는다.

🔴 **SA(동일조건) 사진이 14장 중 10장이다** — 이 화면은 그래서 CC BY-SA 다(남이 가져다 써도
막을 수 없다). 2026-09-18 개발자가 **감수하기로 결정**했다. 줄이는 길은 5절.

🔴 **로봇이 강제 push 와 남의 브랜치에서는 안 돈다** — 브랜치를 다시 세워 force-push 하자
표식 파일이 한 글자도 안 바뀌었는데 로봇이 돌아 후보 4장을 다시 커밋했다(GitHub 은 강제 push 에서
`paths:` 를 못 가린다). `if: !github.event.forced` + 표식의 `branch:` 줄 대조로 막았다.

## 5. 승인받은 컷 A 와 다른 것 다섯 (숨기지 않고 적는다)

승인 대상은 `tools/gate-reel/reel.html` 이 그린 **컷 A**(경희대 → 한국외대 → 서울대 · 9초)다.
관문이 시간·곡선을 그 파일과 **대조**하므로 둘은 갈라지지 않는다. 다만 다섯 가지는 다르다.

1. 출처 줄에서 **'정문' 을 뺐다** — 연세대 언더우드관 · 건국대 일감호처럼 정문이 아닌 사진이 있다
   (확인 안 한 것을 단정하지 않는다 · 원칙 8-1).
2. 출처 줄 글자 9px → **11.5px**(`--t-2xs`, 척도 최소값).
3. 워드마크 16px → **17px**(`--t-lg`).
4. 제목 32px 는 척도에 없어 **`--t-start` 를 시작 화면 전용으로 하나 더했다**(27 과 38 사이라
   '단계마다 1.07배' 관문은 지킨다 · DESIGN.md 척도 표에 예외로 적었다).
5. **사진을 못 받았을 때** — 목업에 없던 경우다. 지어내지 않고 바탕색 위에 글과 버튼만 남긴다.

**실측(실제 앱 390×844)**: 워드마크 62px · 학교 이름표 64px · 스크림 464px(아래 45%) ·
카피 510px · 버튼 685px · 헛스크롤 0 · 버튼 흰 면(#fdfbf6) + 남색 글자(#1e2b42).
