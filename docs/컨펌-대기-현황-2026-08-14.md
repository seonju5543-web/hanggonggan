| 지원 자격을 아직 못 읽음 | 75건 | "지원 자격을 아직 읽지 못했어요"로 정직하게 표시 |

이 셋은 **컨펌으로 풀리지 않습니다.** 양식은 Claude API 잔액, 자격은 같은 잔액이 열쇠입니다
(근거·비용: `docs/API-활용방안-2026-08-12.md`).

## 4. 가장 빨리 끝내는 순서

1. **관리자 화면 → 컨펌 작업대** (https://hanggonggan-admin.pages.dev#review)
2. 위쪽 묶음 버튼 **`마감 임박만`** → 나온 것 전체 선택 → **`검수 완료로`** — 위 1-①의 마감 있는 10건이 몇 초에 끝납니다
3. 그다음 **`경고등 없는 것만`** → 전체 선택 → `검수 완료로` — 마감 미확인분 중 문제 없는 것
4. 남는 것만 한 건씩 — 원문을 나란히 보며 판단
