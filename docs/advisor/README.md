# 기술 고문 요청서 (2026-09-03)

외부 개발 고문에게 **학교 장학 시스템 연동**을 상담하기 위해 만든 문서다.
앱의 구조·코드·데이터를 전부 공개하고, 개발자가 답할 수 있는 형태의 질문 열을 담았다.
04장은 **학교 연동**(Q1~Q5), 05장은 **지금의 구조**(Q6 회원 데이터 모델 · Q7 확장성 ·
Q8 SDK 없이 직접 호출 · Q9 수집 범위 · Q10 개발 방식)다.

| 파일 | 무엇 |
|---|---|
| `한대장_기술고문_요청서.pdf` | 배포본 (A4 26쪽) — 이걸 보내면 된다 |
| `tech-advisor-brief.html` | 원본. 고칠 때는 이 파일을 고친다 |
| `render.js` | HTML → PDF 렌더러 |

## 다시 만들기

```
npm i playwright-core          # 한 번만
node docs/advisor/render.js
```

한글 폰트(약 40MB)는 `render.js` 가 `docs/advisor/fonts/` 에 자동으로 내려받는다.
**폰트는 저장소에 넣지 않는다** — 코드보다 크고, 언제든 다시 받을 수 있다.
