# Vercel 배포 검토

> 2026-10-10 · 유은서(CTO) · 팀 업무 분장 백엔드 3번
> 결론부터: **지금 Vercel로 옮길 이유는 약하다. 옮긴다면 Cloudflare Pages가 우리에게 더 맞는다.**
> 다만 "도메인 구입 + 저장소 비공개 전환"을 할 때가 배포처를 옮길 적기라, 그때 다시 정한다.

## 1. 지금 구조 (바꿀 대상이 무엇인지)

| 무엇 | 어디서 돌아가나 | 비용 |
|---|---|---|
| 학생 앱 (화면 파일) | GitHub Pages — `main`에 올리면 자동 배포 | 0원 |
| 관리자 화면 | Cloudflare Pages + Access 잠금 | 0원 |
| 푸시 알림·AI 초안·도우미 서버 | Cloudflare Workers | 0원 (무료 한도 안) |
| 회원 장부 | Supabase (서울) | 0원 (무료 등급) |
| 수집 로봇 | GitHub Actions | 0원 (공개 저장소라 무제한) |

Vercel이 대신할 수 있는 것은 **첫 줄(학생 앱 배포)** 과 서버 일부뿐이다. 로봇·장부는 그대로 남는다.

## 2. Vercel로 옮기면 좋아지는 것

1. **미리보기 주소** — 브랜치마다 자동으로 시험용 주소가 생긴다. 사장님께 "배포 전 화면"을 링크 하나로 보여 줄 수 있다.
   (지금은 배포 전 화면을 보려면 시안을 따로 만들어야 한다.)
2. **비공개 저장소에서도 배포** — GitHub Pages는 무료로는 공개 저장소만 배포한다. 저장소를 비공개로 바꾸는 순간 앱이 내려간다(CLAUDE.md 기술 사실). Vercel은 비공개여도 된다.
3. **도메인 연결·HTTPS가 쉽다** — 몇 번 클릭이면 된다.
4. **배포 되돌리기** — 이전 배포로 버튼 한 번에 돌아간다.
5. **방문 통계(Web Analytics)** — 쿠키 없이 방문 수를 본다(유료 기능 일부).

## 3. 걸리는 것 (옮기기 전에 꼭 알아야 할 것)

1. 🔴 **무료(Hobby) 요금제는 상업적 사용 금지**다. 우리는 크레딧 유료화·B2B 광고를 계획하므로(BUSINESS.md)
   **Pro 요금제가 필요하다 — 팀원 1명당 월 $20.** 3명이면 월 약 8만 원이다.
   Cloudflare Pages는 무료 등급에서도 상업적 사용이 된다.
2. **로봇은 그대로 GitHub에 남는다.** 로봇이 기본 브랜치에 커밋 → main으로 옮김 → 배포의 흐름이라,
   Vercel이 어느 브랜치를 배포할지 다시 정해야 한다. 로봇 커밋이 하루 10~20번이라 그때마다 다시 배포하면
   무료 한도(빌드 횟수)를 빨리 쓴다. 감시 경로 설정이 필수다(관리자 화면 Cloudflare 때와 같은 문제).
3. **우리 서버는 Cloudflare Workers로 이미 짜여 있다.** Vercel 함수로 옮기려면 다시 써야 하고 얻는 것이 없다.
4. 🔴 **앱 주소가 바뀌면 푸시 알림 구독이 전부 끊긴다.** 구독은 주소에 묶여 있다. 사용자가 적은 지금이 가장 싸게 옮길 때이고,
   옮긴다면 **새 도메인으로 한 번에** 옮겨야 두 번 끊기지 않는다.
5. **앱 주소가 박힌 곳 8군데**(메일 서버 CORS, 푸시 서버 APP_ORIGIN, 실제 앱 확인 워크플로, 제안서 등)를 같이 고쳐야 한다.
6. **관리자 화면이 새어 나갈 위험** — 지금 관리자 화면이 학생 주소에 안 뜨는 근거는 "GitHub Pages가 밑줄 폴더(`_admin/`)를
   배포하지 않는다"는 것 하나다. Vercel·Cloudflare에는 그 규칙이 없으므로 **명시적으로 제외**해야 한다.

## 4. 비교

| | GitHub Pages (지금) | Vercel | Cloudflare Pages |
|---|---|---|---|
| 상업적 사용 무료 | O | **X (Pro 월 $20/인)** | O |
| 비공개 저장소 배포 | X (유료) | O | O |
| 브랜치별 미리보기 주소 | X | O | O |
| 트래픽 한도(무료) | 월 100GB 권장 | 월 100GB | 사실상 무제한 |
| 우리 서버(Workers)와 한 회사 | X | X | **O** |
| 관리자 화면 잠금(Access) | – | 유료 기능 | **이미 쓰는 중** |

## 5. 제안

- **지금은 옮기지 않는다.** 배포 때문에 막힌 일이 없다.
- **옮길 시점 = 도메인을 사서 연결할 때**(백엔드 1번)와 **저장소를 비공개로 바꿀 때**. 이 둘을 한 번에 한다.
- 그때 배포처는 **Cloudflare Pages**를 권한다(상업적 사용 무료, 서버·관리자 화면과 한 곳, 미리보기 주소도 있음).
  Vercel의 장점인 미리보기 주소는 Cloudflare에도 있다.
- 순서(앱이 한순간도 안 죽게): ① 새 배포처에 올리고 새 도메인으로 정상 동작 확인 → ② 주소 박힌 8곳 수정 → ③ 옛 주소에서 새 주소로 안내
  → ④ 그다음에 저장소 비공개 전환. **①보다 ④를 먼저 하면 그 순간 앱이 404가 된다.**
