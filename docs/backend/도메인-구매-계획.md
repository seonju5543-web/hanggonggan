## 1. 왜 지금 사는가

- 지금 주소 `seonju5543-web.github.io/hanggonggan` 은 개인 계정 이름이 박혀 있고 길다.
- **푸시 알림 구독은 주소에 묶여 있다.** 주소를 나중에 바꾸면 그날 전부 끊긴다. 사용자가 적은 지금이 가장 싸다.
- 배포처를 옮기거나(Vercel/Cloudflare 검토) 저장소를 비공개로 바꾸려면 **먼저 우리 주소**가 있어야 앱이 끊기지 않는다.
- PC 웹사이트·홈페이지(백엔드 5번)도 같은 도메인 아래 붙인다.

## 4. 사고 나서 할 일 (순서대로 — 앱이 끊기지 않게)

1. Cloudflare에 도메인 추가 → 네임서버 연결.
2. `app.` 또는 대표 주소를 지금 앱(GitHub Pages)에 연결해 동작 확인. (GitHub Pages도 사용자 도메인을 받는다 — 배포처를 옮기지 않아도 된다.)
3. `admin.` → 관리자 화면(Cloudflare Pages + Access)에 연결. **Access 잠금이 새 주소에도 걸렸는지** `admin-lock-check` 워크플로로 확인.
4. 앱 주소가 박힌 8곳 수정(메일 서버 CORS, 푸시 서버 APP_ORIGIN, check-live 워크플로, 제안서 등 — `docs/backend/vercel-배포-검토.md` 3절).
5. Supabase 로그인 돌아올 주소(Redirect URL)에 새 주소 추가. 안 하면 **비밀번호 재설정·소셜 로그인이 옛 주소로 튕긴다.**
6. 옛 주소에서 새 주소로 안내(옛 주소는 최소 몇 달 유지).

## 5. 관리 규칙

- **자동 갱신 켜기 + 결제 카드 만료 확인.** 도메인이 만료되면 앱·메일·로그인이 한꺼번에 끊기고, 남이 가져갈 수 있다.
- 등록처 계정은 **개인이 아니라 팀 공용 이메일**로 만든다(담당자가 바뀌어도 잃지 않게). 2단계 인증 필수.
- 비용 청구 건은 단톡방 공지 후 진행.
