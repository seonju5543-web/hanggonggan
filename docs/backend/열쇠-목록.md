# 열쇠 목록

> 2026-11-11 · 유은서(CTO) · 출시 전 백엔드 9번 — GitHub 관리자 열쇠가 아무도 모르게 11/7 에 만료됐다.
> 🔴 **열쇠 값은 여기에도, 채팅에도 적지 않는다.** 이름·두는 곳·만료일만 적는다. 값은 GitHub Secrets · Cloudflare · 관리자 화면에만.

- **원본은 `docs/backend/keys.json` 하나다.** 아래 표는 `node tools/key-expiry.mjs --render` 가 그 파일로 다시 쓰는 사본이다(관문이 둘이 같은지 본다).
- **매일 08:43(KST)** 로봇(`.github/workflows/key-expiry.yml`)이 만료됐거나 **14일 안에** 만료되는 열쇠를 찾아 세 사람에게 경보 이슈(「🔑 열쇠 만료가 다가옵니다」)를 연다. 만료일을 새 날짜로 고치면 다음 날 스스로 닫힌다.
- **열쇠를 새로 발급하면**: 넣을 곳에 넣고 → `keys.json` 의 `expires` 를 새 만료일로 고친다(Claude 세션에 "열쇠 만료일 고쳐줘"라고 해도 된다).
- **로봇·서버에 새 열쇠를 쓰면** 이 목록에도 적어야 한다 — 워크플로의 `secrets.이름` 과 서버 README 의 `wrangler secret put 이름` 이 목록에 없으면 관문이 빨개진다.
- 만료일 `확인 필요` 는 아직 모르는 것이다 — 경보는 안 하고 매일 실행 요약에 적는다. 확인하면 날짜(또는 `없음`)로 바꾼다.
- 인스타 토큰은 `insta-token-check.yml` 이 남은 날을 따로 잰다(`자동 확인`).
