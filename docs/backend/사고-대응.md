# 사고 대응 — 한 장

> 2026-11-13 · 유은서(CTO) · 출시 전 백엔드 12번
> 무언가 이상하면 **이 표에서 증상을 찾고 오른쪽 순서대로**. 모르겠으면 Claude 세션에 증상 그대로 말하면 된다("앱이 하얗게 나와", "공고가 안 늘어").
> 🔴 어떤 경우에도 **열쇠·비밀번호 값을 채팅·이슈에 붙여넣지 않는다.**

## 1. 증상 → 할 일

| 증상 | 먼저 볼 곳 | 할 일 |
| --- | --- | --- |
| 앱이 안 열림 · 화면이 깨짐 (방금 뭔가 나간 뒤) | Actions › 「앱 화면 검사」 빨간불 이슈 · 「앱 오류가 갑자기 늘었습니다」 이슈 | **되돌리기** — Actions › 「직전 판으로 되돌리기」 › 미리보기 → 번호 넣고 되돌리기 (`docs/backend/되돌리기-사용법.md`) |
| 학생 폰 오류가 갑자기 늘었다는 경보 | 이슈 「🚨 앱 오류가 갑자기 늘었습니다」 → Supabase › Table Editor › `client_errors` 최근 것 | 직전 작업이 원인이면 되돌리기 · 아니면 Claude 세션에 "앱 오류 늘어난 것 봐줘" |
| 새 공고가 안 늘어남 | 「장학공고 수집 리포트」·「🚨 데이터 관문」 이슈 · Actions 의 수집 로봇 | Claude 세션에 "데이터 관문 빨간불 확인해줘" (저장은 대개 그대로 된다 — 원래 있던 빨간불이면 데이터는 지켜진다) |
| 앱에 반영이 안 됨 (로봇은 모았는데) | 이슈 「🚨 앱 배포 동기화 실패」 | 관리자 화면 › 로봇 › 「배포 동기화」 지금 실행 → 안 되면 Claude 세션 |
| 로그인이 안 됨 | 이슈 「🚨 로그인 서버(Supabase) 이상」 · Supabase 대시보드 상태 | Supabase 쪽 장애면 기다린다(앱의 검색·추천은 로그인 없이 돈다) · 열쇠 문제면 이선주 |
| 알림(푸시)이 안 옴 | 이슈 「🚨 푸시 발송 서버 이상」 · Actions › 「푸시 서버 상태 확인」 | 서버가 옛 판이면 Cloudflare 배포 열쇠 확인(이선주) · Actions › push-check 로 시험 발송 |
| 관리자 화면 버튼이 안 먹힘 | 관리자 화면 첫 화면의 열쇠 만료 · 이슈 「🔑 열쇠 만료가 다가옵니다」 | GitHub 열쇠 새로 발급 → 관리자 화면에 넣기 → Claude 세션에 만료일만 알려 주기 |
| 관리자 화면이 잠기지 않음 · 공개 주소에 노출 | 이슈 「🚨 관리자 화면이 잠기지 않았습니다」·「관리자 페이지가 공개 주소에 노출됨」 | **즉시** 이선주 — Cloudflare Access 확인 · `.nojekyll`·`_config.yml` 이 생겼으면 지운다 |
| 공고 내용이 틀림 (금액·마감·학교) | 관리자 화면 › 할 일 | 관리자 화면에서 고친다(검사를 통과해야 저장) · 판정 규칙이 틀린 것 같으면 Claude 세션 |
| 인스타 게시가 멈춤 | 이슈 「🚨 인스타 토큰…」 · Actions › 「인스타 토큰 수명 확인」 로그 | 토큰 재발급 → GitHub Secrets `IG_ACCESS_TOKEN` (`insta/README.md`) |
| 보안 경보 | 이슈 「🛡 보안 코드 점검에서 고칠 것이 나왔습니다」 | Claude 세션에 "보안 점검 경고 고쳐줘" (`docs/backend/보안-점검.md`) |

## 2. 열쇠가 새어 나갔을 때 (채팅·이슈·커밋에 붙여넣음)

1. **그 열쇠를 바로 지운다(폐기)** — 새로 만드는 것보다 먼저. 어디서 지우는지는 `docs/backend/열쇠-목록.md` 의 「바꾸는 법」 칸.
2. 새 열쇠를 만들어 원래 자리(GitHub Secrets · 관리자 화면 · Cloudflare)에만 넣는다.
3. Claude 세션에 **"○○ 열쇠 바꿨어, 만료일 ○월 ○일"** — 목록을 고치고 경보를 닫는다.
4. 커밋에 들어갔으면 지운 커밋으로 덮어도 기록에 남는다 → 폐기가 유일한 해법이다(1번).

## 3. 누구에게

| 무엇 | 누구 |
| --- | --- |
| 저장소 주인 권한(설정 스위치·Secrets·Cloudflare·Supabase·Meta 앱) | 이선주 |
| 판정·로봇·배포·되돌리기 | 유은서 (Claude 세션) |
| 학생 문의 창구 | 앱 고객센터 메일(`support-config.js`) |

## 4. 하지 않는 것

- main 에 직접 고쳐 올리기 · 기록 되감기(강제 push) — 로봇이 모은 공고가 사라진다. 되돌리기는 버튼으로.
- 경보 이슈를 이유 없이 닫기 — 회복하면 로봇이 스스로 닫는다. 손으로 닫을 땐 이유를 댓글로.
- 유료 기능(AI 자격 읽기·초안)을 급하다고 켜기 — 개발자가 채팅에서 지시할 때만.
