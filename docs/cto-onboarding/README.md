갱신할 때는 `src/`의 HTML을 고치고 아래로 다시 렌더링한다(수치를 손으로 고칠 때는 근거 파일을 다시 셀 것).

```bash
npm i playwright-core
node docs/cto-onboarding/src/render-pdf.js
```
