## 어떤 경로로 만들었나

두 갈래를 독립적으로 돌려 개발자가 더 나은 쪽을 고르는 구조로 갔다.

| 경로 | 도구 | 결과물 |
|---|---|---|
| A | **Claude 챗봇** | 프롬프트 + 캡쳐 첨부 → `.pptx` 직접 생성 |

## 재사용할 때의 핵심 지시문

어느 AI를 쓰든 아래 규칙 블록은 **반드시** 프롬프트에 넣는다. 이게 없으면 결과가 무너진다.

```
## 절대 규칙 5가지 — 어기면 실패다
1. 숫자를 절대 바꾸지 마라. 반올림·근사·"약"·"여" 붙이기 전부 금지.
2. 회사명을 쓰지 마라. 경쟁사는 유형으로만 표기한다:
   "대학 공식 포털", "공고 조회형 서비스". 실재하지 않는 회사명을 지어내면 치명적이다.
3. 서술문을 쓰지 마라. "~한다", "~이다", "~합니다" 금지.
   모든 항목은 명사형 종결, 한 줄 12자 이내. 슬라이드당 최대 4개 항목.
4. 내가 준 것 외의 사실을 만들지 마라. 빈 것은 빈 채로 둬라.
5. 출처 표기를 유지하라: [자사] [공개] [목표] [추정]

## 청중
대학 교수·산학협력단 심사역. 전문성 매우 높음.
7분 발표 + 8분 질의응답. 심사위원은 서면 사업계획서를 이미 읽었다.
이 덱은 요약이 아니라 "이미 만들어 놓고 돌리고 있다"의 증명이다.
과장 금지: "혁신적", "최고의", "게임체인저" 사용 금지.

## 디자인
- 16:9. 색: 주색 #0F2A4A · 강조 #E8890C · 보조 #5A6B7D · 카드 #F4F6F8 · 배경 #FFFFFF
- 강조색은 슬라이드당 1~2회만. 경쟁 대상은 전부 회색조
- 폰트: 국문 Pretendard(없으면 Noto Sans KR), 숫자 Inter
- 제목 30~34pt Bold / 키워드 16~18pt / 스탯 숫자 44~60pt Bold / 핵심 문구 18~20pt / 각주 10pt
- 표지와 마지막 장만 남색 배경
- 금지: 그라데이션 · 3D · 그림자 · 제목 밑줄 · 색 띠 · 사이드 스트라이프 · 스톡 사진 · 애니메이션
- 반복 컴포넌트 3종으로 통일:
  ① 스탯 카드(연회색 배경, 큰 주황 숫자 + 작은 라벨)
  ② 남색 강조 박스(핵심 문구용, 슬라이드당 1개)
  ③ 비교 표(헤더 남색, 우리 열만 연주황)

## 사진 자리
[이미지 N: 설명] 표시가 있는 곳은 회색 사각형 + 안내 텍스트로 자리만 잡아라.
대체 이미지나 스톡 사진을 절대 넣지 마라.

## 자체 점검 (만든 뒤 결과를 알려 줄 것)
1. 글자가 상자 밖으로 넘치거나 잘린 곳
2. 요소끼리 겹친 곳
3. 숫자가 내가 준 값과 전부 일치하는가
4. 회사명이 하나라도 들어갔는가
5. 서술문("~한다/~합니다")이 남아 있는가
```

슬라이드별 내용은 `02_슬라이드구성.md`, 사실 출처는 `01_현황블록.md`를 그대로 붙여 쓴다.

## 도구별로 겪은 문제 (다음에 같은 실수 안 하려고 기록)

| 도구 | 문제 | 대응 |
|---|---|---|
| **Canva Magic Design** (맨땅 자동 생성) | 숫자를 반올림하고 **경쟁사를 지어내 채운다.** 서술문으로 되돌린다 | **쓰지 않는다.** 템플릿을 먼저 씌우고 내용만 채우게 하는 방식으로 우회 |
| Canva 전반 | PPTX 내보낼 때 폰트가 치환될 수 있음 | **PDF로도 내보내 백업.** 발표장 PC에서는 PDF가 안전 |
| Claude 챗봇 | 파일 생성 기능이 없으면 .pptx를 못 만듦 | pptxgenjs 스크립트로 받아 실행하는 대안을 프롬프트에 명시 |
| Claude Code (`build_deck.js`) | 첫 렌더에서 결함 4건 (글자 겹침·넘침·줄바꿈 깨짐·표와 박스 충돌) | 렌더 후 눈으로 확인 필수. LibreOffice Impress 모듈이 없으면 설치해야 렌더됨 |
| GitHub 커넥터 | 검색 목록에 안 나옴(필터 문제 추정) | **불필요.** 저장소가 공개라 링크로 충분 |

## 참고 — 이 저장소 문서를 AI에게 줄 때의 함정

| 파일 | 왜 주면 안 되나 |
|---|---|
| `README.md`(루트) | **v0.2 시절 그대로.** "원클릭 신청", "신청완료 → 서류검토" 표현이 현재 정직 원칙과 충돌. 챗봇이 읽으면 "원클릭 신청 완료"라고 쓴다 |
| `CLAUDE.md` | 207KB로 너무 큼. 내부 사고 기록·미완성 항목 다수 |
| `PROGRESS.md` | 숫자가 낡음(166건 vs 실제 171건) + 내부 이슈 섹션 |
| `data/*.json` | 240~470KB |

**대신 `01_현황블록.md`를 준다.** 링크는 배포된 앱 하나면 충분하다.

## build_deck.js

Claude Code가 직접 PPTX를 만든 스크립트. 실행법:

```bash
npm install pptxgenjs
node build_deck.js
```

⚠️ 이 스크립트는 **초기 15장 버전**이다. 이후 대화에서 키워드형 전환·기능 확충·코드 대조 정정을
거쳐 **본편 11장 + 백업 8장**으로 확정됐으므로, 재생성할 때는 `02_슬라이드구성.md`를 기준으로
내용을 갱신해야 한다.
