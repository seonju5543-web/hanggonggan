GitHub 열쇠를 넣어야 화면이 열립니다. 열쇠가 없으면 아무 내용도 표시되지 않습니다.

열쇠 만드는 방법

저장소 주인(선주님) — GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token

  1. Repository access: Only select repositories → hanggonggan 하나만
  2. Permissions — Actions: Read and write · Contents: Read-only · Metadata: Read-only
  3. 만료일은 30~90일로 두세요. 지나면 새로 만들면 됩니다.

공동작업자 — 위 방식은 안 됩니다. 세밀 권한 열쇠는 자기가 가진 저장소에만 붙어서, 남의 저장소에는 만들 수 없습니다. 대신 → Developer settings → Tokens (classic) → Generate new token → 범위 repo와 workflow 두 개만 체크.

파일 쓰기 권한을 주지 않는 이유: 이 열쇠가 새어도 남이 저장소 내용을 마음대로 바꿀 수 없게 하기 위해서입니다. 관리자 화면의 변경은 검사를 통과해야만 저장되는 정해진 절차를 통해서만 이루어집니다.
