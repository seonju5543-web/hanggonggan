# 진짜 푸시 켜기 — 개발자가 할 일 (약 15분, 무료)

> **이걸 하고 나면**: 사용자가 앱을 켜지 않아도, 화면이 꺼져 있어도
> 토스·테무처럼 **폰에 알림이 도착**합니다. 지금은 앱을 열어야만 알림을 확인할 수 있어요.

---

## 왜 서버가 필요한가 (1분 설명)

한대장은 서버 없이 파일만 올려 두는 방식(GitHub Pages)이라 **아무도 폰에 말을 걸 수 없습니다.**
알림을 보내려면 "지금 확인해 봐"라고 폰을 두드려 줄 **작은 서버 하나**가 필요합니다.

그래서 만든 게 이 폴더입니다. 특징:

- **무료**입니다 (Cloudflare 무료 등급 — 카드 등록 없이 가입 가능)
- **아주 작습니다** — 하는 일은 "폰 깨우기" 하나뿐
- **개인정보가 서버로 가지 않습니다** — 서버에 저장되는 건 *폰 주소 + 학교*뿐이고,
  "○○장학금 내일 마감" 같은 문구는 **폰 안에서** 만들어집니다.

---

## 준비물

- 컴퓨터에 **Node.js** (이미 설치돼 있습니다)
- **Cloudflare 계정** (무료 · https://dash.cloudflare.com/sign-up · 이메일만 있으면 됩니다)

---

## 1단계 — 열쇠 만들기 (1분)

저장소 폴더에서:

```bash
node server/push/gen-vapid.mjs
```

화면에 **① 공개키**와 **② 서버에 넣을 명령 3줄**이 나옵니다. **이 창을 닫지 마세요.**

> 🔑 공개키는 공개돼도 안전한 값이고, 개인키(VAPID_JWK)는 **서버에만** 넣습니다.
> 개인키를 GitHub에 올리면 안 됩니다. (실수로 올렸다면 다시 만들어 교체하면 됩니다.)

## 2단계 — 서버 올리기 (10분)

```bash
cd server/push

# ① Cloudflare 로그인 (브라우저가 열립니다)
npx wrangler login

# ② 구독 저장소 만들기 — 나오는 id를 wrangler.toml의 '여기에_KV_ID_붙여넣기' 자리에 붙여넣으세요
npx wrangler kv namespace create SUBS

# ③ 1단계 화면에 나온 secret 명령 3개를 그대로 실행 (VAPID_PUBLIC / VAPID_JWK / VAPID_SUBJECT)

# ④ 올리기
npx wrangler deploy
```

마지막에 이런 주소가 나옵니다 → **이 주소를 복사해 두세요.**

```
https://handaejang-push.○○○.workers.dev
```

잘 올라갔는지 확인:

```bash
curl https://handaejang-push.○○○.workers.dev/health
# {"ok":true,"configured":true} 가 나오면 성공
```

## 3단계 — 앱에 연결 (1분)

저장소의 **`push-config.js`** 파일을 열어 두 줄을 채웁니다.

```js
const PUSH_CONFIG = {
  endpoint: 'https://handaejang-push.○○○.workers.dev',   // 2단계에서 나온 주소
  publicKey: 'B...',                                      // 1단계의 ① 공개키
};
```

저장하고 `main`에 올리면 끝입니다. (Claude에게 "푸시 설정 채웠어, 배포해줘"라고 하셔도 됩니다.)

> ⚠️ 주소가 `.workers.dev`가 **아닌** 다른 도메인이면 `index.html`의 보안 설정(CSP)에
> 그 도메인을 추가해야 합니다 — Claude에게 주소를 알려주면 처리합니다.

---

## 잘 되는지 확인하기

1. 폰에서 앱을 열고 **MY → 알림 → 켜기**
2. 그 아래 **"앱을 켜지 않아도 받기" → 켜기**
3. 앱을 완전히 닫고, 컴퓨터에서 한 번 깨워 봅니다:

```bash
# 관리자 열쇠를 먼저 정해 두세요 (아무 긴 문자열)
npx wrangler secret put ADMIN_KEY

curl -X POST https://handaejang-push.○○○.workers.dev/run \
  -H "x-admin-key: 방금-정한-열쇠"
```

폰에 알림이 뜨면 성공입니다. 이후에는 **매일 아침 8시 10분 · 저녁 8시 10분(한국시간)**
자동으로 돌면서, 알릴 거리가 있는 학교의 사용자만 깨웁니다.

## 기기별로 되는 것 / 안 되는 것 (정직하게)

| 기기 | 앱을 안 켜도 알림이 오나 | 조건 |
|---|---|---|
| **안드로이드 (크롬)** | ✅ 옴 | 없음 (홈 화면에 설치하면 더 안정적) |
| **아이폰 (사파리)** | ✅ 옴 | **홈 화면에 추가(설치) 필수** · iOS 16.4 이상 |
| **PC (크롬/엣지)** | ✅ 옴 | 브라우저가 켜져 있을 때 |
| 아이폰인데 설치 안 함 | ❌ 안 옴 | 앱 화면에 설치 안내가 자동으로 뜹니다 |

- 폰이 완전히 꺼져 있으면 **켜질 때 도착**합니다(최대 12시간 보관).
- 사용자가 알림을 끄면 서버 등록도 함께 해지됩니다.

## 비용

Cloudflare 무료 등급 한도는 **하루 10만 요청 / KV 하루 10만 읽기**입니다.
사용자 1,000명 기준 하루 사용량은 요청 2,000건 수준이라 **한참 남습니다.**
사용자가 수만 명이 되면 그때 유료(월 $5)를 검토하면 됩니다.

## 끄고 싶으면

`push-config.js`의 두 값을 다시 빈 문자열로 만들고 배포하면 됩니다.
앱은 예전처럼 "앱을 열 때 확인하는 알림"으로 조용히 돌아갑니다.
