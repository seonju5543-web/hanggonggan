# 장학금 도우미 AI 서버 (선택 · 아직 배포 안 함)

> **지금 앱은 이 서버 없이도 정상입니다.** 안내봇이 앱 안 정보로 답하고 있고,
> `chat-config.js`의 `endpoint`가 비어 있어 앱은 바깥으로 요청을 **한 건도** 보내지 않습니다.
> 이 서버는 "안내봇이 못 알아들은 질문"만 도와주는 **덤**입니다.

## 이 서버가 하는 일 (그리고 하지 않는 일)

**하는 일**: 학생 질문을 읽고 **어느 공고·어느 원문 문장이 맞는지 골라 줍니다.**

**하지 않는 일**: 답 문장을 쓰지 않습니다.

왜 이렇게 만들었는지가 중요합니다. AI에게 자유롭게 답을 쓰게 하면 **모를 때 그럴듯하게
지어냅니다.** 이 앱이 7월(가짜 공지 금지)·8월(추론 금지)에 지운 바로 그 위험입니다.
그래서 AI를 '작가'가 아니라 **'사서'** 로 씁니다 — 어느 책 몇 번째 문장인지 알려 주는 것까지.

화면에 뜨는 원문 문장은 **앱이 자기 데이터에서 번호로 꺼냅니다.** 서버가 보낸 글자는
화면에 나가지 않습니다. 지어낼 자리가 구조적으로 없습니다.

## 앱이 다시 한 번 검사합니다 (3중 방어)

| 겹 | 어디 | 무엇을 막나 |
|---|---|---|
| 1 | 서버 지시문 | 목록 밖 공고 금지 · 문장 새로 쓰기 금지 · 근거 없으면 `needSource: true` |
| 2 | 서버 응답 정리 | 목록에 없는 id를 떨궈 냄 |
| 3 | **앱** (`chat.js` `chatVerifyAI`) | 앱에 없는 공고 차단 · 인용 번호 범위 밖 차단 · **한 줄 요약에 앱이 모르는 숫자가 있으면 그 줄 폐기** · 근거 0개면 AI 답 자체를 버리고 안내봇 답으로 |

3번이 최후 관문입니다. **서버를 누가 바꿔 놓아도 앱은 지어낸 숫자를 화면에 올리지 않습니다.**

## 올리는 방법 (10분)

1. Cloudflare → Compute → Workers → Create → `server/chat` 폴더를 Root directory(`Path`)로 연결
   (푸시 서버 `handaejang-push`와 같은 방식입니다)
2. 열쇠 넣기 — **저장소에는 절대 넣지 않습니다**
   ```
   npx wrangler secret put ANTHROPIC_API_KEY
   ```
3. 배포되면 나온 주소(`https://handaejang-chat.○○○.workers.dev`)를
   `chat-config.js`의 `endpoint`에 붙여 넣고 배포합니다. **앱 코드는 더 고칠 것이 없습니다.**
4. 끄고 싶으면 `endpoint`를 다시 비우면 됩니다. 그 순간 안내봇만 쓰는 상태로 돌아갑니다.

> ⚠️ **Claude API 잔액이 있어야 동작합니다.** 2026-08-11부터 잔액이 바닥나 있습니다.
> 잔액이 없으면 서버가 `needSource: true`로 답하고, 앱은 조용히 안내봇 답을 내보냅니다
> (학생 눈에는 아무 일도 안 일어난 것처럼 보입니다 — 고장 나 보이지 않습니다).

## 비용

이 서버는 **고르기만** 하므로 답이 짧습니다(공고 번호와 인용 번호 몇 개).
가장 싼 모델(Haiku)을 쓰고, **안내봇이 못 알아들은 질문에만** 부릅니다.
질문 한 건에 원문 몇 문장이 들어가고 나오는 것은 20~40자 수준이라,
자유 문장을 쓰게 하는 방식보다 **10분의 1 수준**입니다.

## 기록을 남기지 않습니다

- KV도 D1도 붙이지 않았습니다. **질문도 답도 저장하지 않습니다.**
- 앱이 보내는 것은 **질문 + 앱이 먼저 골라 낸 공고의 공개 정보**뿐입니다.
  이름·학교·성적·소득구간·특별자격·계좌는 **보내지 않습니다**(`chat.js` `chatAiCandidates`).
  판정은 지금처럼 폰 안에서 끝납니다 — 푸시 서버가 폰 주소·학교·캠퍼스만 갖는 것과 같은 원칙입니다.
