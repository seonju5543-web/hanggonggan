# 신청서 초안 서버 — 올리는 법

앱이 학생의 재료를 문장으로 엮어 **초안**을 만들어 주는 서버입니다.
푸시 서버(`server/push/`)·도우미 서버(`server/chat/`)와 같은 계정에 올리면 됩니다. **무료 등급으로 충분합니다.**

---

## 이 서버가 하는 일과 안 하는 일

| | |
|---|---|
| **한다** | 학생이 준 재료 + 공고의 공개 정보를 Claude에 넘겨 **초안 문장**을 받아 온다 |
| **한다** | 받아 온 초안을 **되받아 검사해서**, 학생이 안 준 사실이 섞였으면 **버린다** |
| **안 한다** | 저장. KV가 없습니다 — 학생이 쓴 글도, 만들어 준 초안도 남지 않습니다 |
| **안 한다** | 민감정보 취급. 주민번호·계좌·서류 스캔·장애/기초수급/국가유공자 여부는 **받으면 400으로 거절**합니다 |
| **안 한다** | 사실 나열형 칸 채우기. 봉사기관·봉사시간·가족사항 칸에는 **아예 가지 않습니다** |

---

## 올리는 순서 (10분)

```bash
cd server/essay
npx wrangler login                      # 브라우저가 열립니다
npx wrangler deploy                     # 주소가 나옵니다 (https://handaejang-essay.○○○.workers.dev)
npx wrangler secret put ANTHROPIC_API_KEY   # 열쇠를 여기에만 넣습니다
```

마지막으로 **앱의 `essay-config.js`에 그 주소 한 칸만 채우면** 켜집니다.
비워 두면 앱은 지금처럼 학생이 직접 쓰는 방식으로만 돕습니다 — **앱 코드는 고칠 것이 없습니다.**

---

## 🔴 열쇠를 저장소에 넣지 마세요

이 저장소는 공개라 파일에 넣으면 누구나 꺼내 씁니다.
열쇠가 있어야 할 곳은 **Cloudflare 비밀값** 한 곳뿐입니다(`wrangler secret put`).

---

## 값 바꾸기 (`wrangler.toml`)

| 값 | 기본 | 뜻 |
|---|---|---|
| `ESSAY_MODEL` | `claude-sonnet-5` | 서류 1건당 약 **47원**. `claude-opus-5`로 올리면 약 **78원** |
| `ESSAY_EFFORT` | `medium` | 사고 깊이. 자소서는 기계적인 일이 아니라 `low`로 두지 않습니다 |

바꾼 뒤 `npx wrangler deploy` 를 다시 하면 반영됩니다.

---

## 🔴 `fallbacks` 를 붙이지 마세요

`claude-sonnet-5` 는 이 파라미터를 지원하지 않아 **첫 호출부터 400**이 납니다
(2026-08-23 이 저장소에서 실측 — 자격 AI가 같은 이유로 시범 3건이 전부 죽었습니다).
Fable 5 · Opus 5 전용 값입니다.

## 잘 도는지 확인

```bash
node verify/verify-essay-guard.mjs
```

가짜 응답으로 **AI가 일부러 나쁘게 굴게** 해서 안전장치를 검사합니다 — **돈이 들지 않습니다**.
① 없는 수상·봉사시간 ② 앱이 모르는 숫자·날짜 ③ 사실 나열형 칸 ④ 민감정보 —
네 가지가 전부 막히는지 실제 `worker.js`를 불러서 확인합니다.

진짜 API가 이 요청 모양을 받아 주는지까지 보려면 Actions 탭의
**「초안 서버 실물 확인」** 버튼을 누르세요(호출 1회 · 약 50원).
