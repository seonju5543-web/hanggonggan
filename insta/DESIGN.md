# 판형 — 템플릿 3벌

구현 `insta/render.mjs` · 스크립트 규격 `insta/SCRIPT.md`. 결과물은 HTML/CSS → PNG(피그마 안 거침).
🔴 **템플릿이 돌아가는 축이고 색이 아니다.** 씨앗(공고 이름)으로 셋 중 하나를 고른다 —
같은 공고는 늘 같은 얼굴, 공고가 바뀌면 얼굴도 바뀐다.

| 이름 | 무엇을 베꼈나 | 표지 |
|---|---|---|
| `photo` | 개발자가 준 Go.Designer 카드뉴스 | **사진 배경 + 글자만** |
| `chat` | 개발자가 준 레퍼런스 — 카카오톡 대화창 | **잠금화면 알림** |
| `note` | 개발자가 준 레퍼런스 — 아이패드 굿노트 필기 | 노트 첫 장 |

## 반려된 것 — 되돌리지 말 것

개발자가 다섯 번 반려했다. 매번 다른 말이었지만 원인은 하나였다.

| 반려 문구 | 뜻 |
|---|---|
| "그냥 너무 클로드스럽잖아 가운데 정렬 박스에 다 똑같잖아" | 카드마다 같은 리듬 |
| "흰색 박스에 여백이 너무 많다" | 그릇을 두고 글자가 작으니 빈다 |
| "저 ㅈ 같은 네모박스 좀 빼고" | **그릇(흰 카드 프레임) 자체를 뺀다** |
| "박스 모양 없애고 배경에 글씨만 강조하는 느낌으로" | 배경 + 큰 글자 |
| "글씨체는 하나로 통일" | 템플릿당 폰트 한 벌 |
| "밑에 있는 작은 글씨도 다 빼라고" · "밑에 회색 글씨 다 지워" | **카드 바닥 회색 글씨 전부** — `외 n건` 도 |
| "표지의 지역 조건 성적 조건 이건 걷어내줘" | **표지 조건 칩** (조건은 2장이 원문으로 진다) |
| "지원.. 처럼 문장이 끊기는 거" | **곁가지 괄호를 걷어낸다**(`dropParen`) |
| "말 끊기지 말라했지 .. 없도록" | **자르기를 통째로 없앴다** — 글자를 줄여 전문을 담는다 |
| "이건 진짜 조심하세요 말고 다른 말" · "이거 걸리면 못받아요 너무 길어" | `이러면 못 받아요` |
| "경고 이모티콘 대신 앞에 하나 채팅" | 카톡 판형 리드인 말풍선 |
| "인도인이 밥 먹는 사진..? 은 연관성이 떨어지는데" | 교외 사진을 **눈으로 고른 열람실·서가**로 |

🔴 **그릇을 다시 넣지 말 것.** 그릇이 없으면 글자가 커야 화면이 안 빈다 —
빈 자리를 도형·아이콘·이모지로 때우는 순간 그 AI 티가 돌아온다.
🔴 **바닥 회색 글씨를 다시 넣지 말 것** — `.foot2`·`.foot3` 를 걷어냈다.
`외 N건` 도 없앴는데, **버린 게 아니라 자격제한을 전부 싣기로 바꾼 것**이다
(3줄만 싣고 나머지를 흐린 글씨로 미루면 걸리는 조항이 거기 있어도 안 읽힌다).
사진 저작자 표시(`.cred`)만 남는데 CC BY 조건이라 뺄 수 없다.
⚠️ 바닥글을 없앴으면 `.plain` 의 아래 여백도 같이 줄이고 `.items` 를 `space-evenly` 로
둘 것 — 안 그러면 항목이 둘일 때 카드 아래가 통째로 빈다(실제로 그랬다).
🔴 반려된 판형의 CSS(`.sheet` `.tabs` `.pin` `.ftab` `.chrome` `.cover` `.half` `.stair`
`.flip` `.coverB` `.sideL` `.bigN` `.listB` `.last` `.promo`)는 **2026-09-09 에 걷어냈다**
— 55개 클래스가 아무 데서도 안 쓰이고 있었다.

## AI 티가 났던 아홉 — 2026-09-10 감사

전수로 재고 고쳤다. 🔴 **되돌리지 말 것** — 각 줄이 그때의 실측이다.

| # | 무엇이 | 실측 | 어떻게 고쳤나 |
|---|---|---|---|
| 1 | 표지 문장 3종, 둘이 81% | 145건 전수 | 6종으로 — 선발인원·마감일 갈래 추가, 겹치던 윗줄 분리 |
| 2 | 사진 3장 아래 371px 공백 | 카드의 27% | `.kv2`·5장을 `space-evenly` 로 |

| 4 | 굿노트 5장이 같은 틀 | — | 검은 막대·테두리 박스 제거, 장마다 다른 표시 |

| 9 | 표지에 재단명이 두 번 | 55/145 | 겹칠 때만 위 라벨을 공고명으로 |

🔴 **표지 후킹에 상대 날짜를 쓰지 말 것** — 사진은 굳는데 게시물은 피드에 남는다.
`1일 뒤 마감` 은 내일 거짓말이 된다. 절대 날짜(`9월 11일 마감`)는 안 늙는다.
🔴 **색 원 안에 아이콘·이모지를 다시 넣지 말 것.** AI 슬롭 목록의 대표 항목이고,
한 판형 안에서 은유가 세 번 바뀌었다(순번/부정/이모지).
⚠️ CSS 는 템플릿 문자열이라 **주석 안 백틱이 문자열을 끊는다**(실제로 겪었다).

## 폰트 — 템플릿당 한 벌

| 템플릿 | 폰트 |
|---|---|
| `photo` | Noto Sans KR (400/500/900) |
| `chat` | Noto Sans KR (400/900) |
| `note` | Gaegu (400/700) — 손글씨 |

🔴 **폰트가 안 실리면 전부 두부(□)가 되는데 로그는 초록불이다.** 그래서 렌더러가
`document.fonts.load()` **결과 배열의 길이**를 보고 안 실리면 종료 코드 1로 죽는다.
⚠️ `fonts.check()` 를 쓰면 안 된다 — **맞는 FontFace 가 하나도 없으면 참을 돌려준다**
(CSS Font Loading 규격). 두부가 되는 바로 그 경우를 통과시켰다. **관문 C7**.
⚠️ 시험 글자도 한글이어야 한다 — 기본값 `BESbswy` 는 한글 서브셋에 없어 늘 거짓이 된다.

🔴 **'학교가 안 드러난다' 와 '주제와 이어진다' 는 다른 조건이다.** 검색에 맡겼더니
이바단 도서관·1918년 베이징대·미술 작가책이 표지에 깔렸다(개발자 지적). 지금은 **눈으로
고른 파일 이름을 박아 둔다** — 교내와 같은 방식. 위키미디어 공용에 한국 대학 공부 장면은
거의 없다(실측 0장)라 학교를 못 알아보는 **열람실·서가**로 간다.
⚠️ 버린 것: 역사 사진(칼라일 인디언 학교·로워 수용소) · 지역색이 센 것 · 미술 작가책.
🔴 **주소를 받아만 오면 안 된다** — 실제로 그려지는지 확인하고 남긴다(`alive()`).
Openverse 가 준 42장 중 8장만 열렸다(핫링크 차단·404). 그래서 Openverse 는 걷어냈다.
🔴 위키미디어 주소는 API 가 준 `thumburl` 을 그대로 쓴다 — 손으로 조립하면 400 이 온다.
🔴 **저작자 이름을 글자 수로 자르지 말 것** — 26자로 자르던 시절 `Joe Mabel as Flickr user J`
가 남았다. CC BY 에서 반쪽 이름은 안 하느니만 못하다. **관문 I8**.
🔴 저작자·라이선스는 **표지 카드 위**에 박는다. 캡션은 두 줄 뒤로 접혀 안 보인다.
· CC BY-SA 도 쓴다: 동일조건은 그 카드 이미지 하나에만 걸리고 앱·브랜드로 안 번진다.
· 배경 사진이 404 면 표지가 통째로 까매지는데 로그는 초록불이었다 → 지금은 시끄럽게 죽는다.

## 색

`photo` 판형만 색을 갈아 끼울 수 있다(`--skin=blue|marker|folder|minimal`).
`chat` 은 카카오톡, `note` 는 종이라 색이 고정이다 — 바꾸면 베낀 레퍼런스가 무너진다.
다른 템플릿에 `--skin` 을 주면 **조용히 무시하지 않고 경고한다**.

🔴 앱(`style.css`)의 조용한 잉크+놋쇠 팔레트를 그대로 쓰지 않았다. 앱은 조용해야
맞지만 피드에서 조용한 것은 곧 안 보이는 것이다.

## 표지 제목 크기

🔴 **고정 크기로 두면 긴 재단명이 카드 밖으로 나간다** — `천안사랑장학재단` 의 `단` 이
오른쪽 테두리를 넘었다(넘침 가드의 ±2px 여유 안이라 안 걸렸다). `headSize()` 가 가장 긴
줄로 88~152px 사이에서 정한다.

## 글자 크기 — 코드가 아니라 브라우저가 정한다

🔴 어림식으로 정하던 두 판이 다 틀렸다: 말풍선 **개수**만 세니 긴 원문에서 잘렸고,
글자 수로 어림하니 짧은 카드에 여백이 남았다. 지금은 **넉넉하게 그려 두고 브라우저가
실제로 재서** 1px 씩 줄인다 — `insta/fit.mjs` 의 `shrinkToFit`.
🔴 이 파일을 **베끼지 말 것**. 렌더러와 스윕 도구가 같은 파일을 쓴다 — 갈라지면
"렌더는 초록불인데 검사만 빨간불" 이 된다. 관문 C5 가 `getBoundingClientRect` 가
다른 파일에 나타나면 실패시킨다.
· 줄어드는 것은 `data-fit`(사진·굿노트의 사실 줄)과 `data-fit-box`(카톡 말풍선 전체)뿐.
· 한 카드 안에서는 **같은 크기**로 움직인다 — 줄마다 다르면 지저분하다.

## 넘침

`kbody` 는 아래 정렬이라 넘치면 **위부터** 잘리고, `items`·`notes` 는 아래가 잘린다.
어느 쪽이든 글자가 조용히 사라지고 로그는 초록불이었다.

🔴 **`scrollHeight` 로 재면 안 된다.** 넘치는 것은 안쪽 상자가 아니라 **카드**이고,
위로 넘친 것은 `scrollHeight` 에 아예 안 잡힌다 — 첫 판이 그래서 **한 번도 안 울렸고**,
그 조용함을 "넘침 0건" 이라고 문서에 적기까지 했다. 지금은 **카드 테두리를 벗어난 자식**이
있는지를 본다(`getBoundingClientRect`). 잘리면 종료 코드 2 로 끝난다.

카톡 판형은 말풍선이 5·6개가 되면 넘쳤다(실측 12건 중 8건). 지어내 줄일 수 없으니
(원칙 8-1) **말풍선 수로 글자를 줄인다**(`.kbody.s5`·`.s6`).
실측 **145건 × 템플릿 3벌 = 435장, 넘침 0** — 고치기 전 같은 잣대로는 8/12 가 빨간불이었다.
다시 재려면 `node insta/sweep-overflow.mjs`(약 3분).

## 아직 헐렁한 곳 (알고 남겨 둔 것)

- **조항이 2개뿐인 공고는 4장이 헐렁하다.** 데이터가 짧은 것이라 판형으로는 못 메운다.
- **2장에 추상적인 자격 줄이 그대로 올라간다**(`학습의지와 생활의지가 강한 자`).
  원문 그대로 원칙이라 버리진 못한다. 표지 후킹에서만 건너뛴다.
