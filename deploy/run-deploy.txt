# 이 기기에서 앱(main)에 배포하기 — push-to-run 표식 파일
#
# 쓰는 법 (둘 중 아무거나)
#   ① Actions 탭 → '이 기기에서 배포 (작업 브랜치 → 앱)' → Run workflow
#      → 배포할 브랜치를 고르고 실행. (이 파일을 안 고쳐도 된다)
#   ② 아래 branch 줄에 **지금 작업 중인 브랜치 이름**을 적고 메모를 아무거나 고쳐 push.
#      그 push 하나로 배포가 돈다 (collector/run-*.txt 와 같은 방식).
#
# 🔴 branch 줄이 왜 필요한가: 이 파일은 기본 브랜치를 통해 모든 작업 브랜치로 퍼진다.
#    브랜치 이름을 적어 두지 않으면, 다른 사람이 기본 브랜치를 병합해 받는 것만으로
#    그 사람의 **아직 덜 된 작업이 앱에 나가 버린다.** 그래서 로봇은 이 줄과 실제로
#    push 된 브랜치가 **같을 때만** 배포한다.
#
# 배포되는 경로: 작업 브랜치 → 기본 브랜치(claude/nice-heisenberg-WESq5) → main → 앱
